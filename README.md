# 📚 Library Management System

## Project Description
This is a simple Library Management System built using HTML, Node.js, Express, and MySQL.

## Technologies Used
- Frontend: HTML, JavaScript
- Backend: Node.js, Express
- Database: MySQL

## Features
- Add books
- View books
- Update books
- Delete books

## How to Run the Project
1. Start MySQL server
2. Go to backend folder
3. Run:
   npm install
   node server.js
4. Open frontend/index.html in browser
